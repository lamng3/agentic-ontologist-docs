The agentic ontologist

One orchestrator and four memory-augmented subagents integrate two ontologies. Every question a subagent asks goes to the cheapest tier that can settle it.

KROMA settles exact label and synonym matches first, and never asks again about a class it settled, which is KROMA's refinement step in this setting. Tied conflicts go to a review queue for a person.

Routing

  1. Evidence. At or above accept, the question takes the answer the evidence supports; at or below reject, the fallback. No model is called.
  2. Local model. The rest go to the local model in batches of 8; an answer with confidence at least local_trust is kept.
  3. API model. The rest go to the API model in batches of 20, while the Budget (calls or list-price dollars) lasts. Past it, the local answer stands and the decision is marked budget.

A model that fails or leaves a question out of its reply does not stop the run: the question falls back to the next answer available.

Recalibration

Every escalated question the local model also answered is a labeled example of how far the local model can be trusted. After each API batch, local_trust becomes the lowest confidence at which the local model agreed with the API model at least 90% of the time, over at least 10 examples. Each change is written to the blackboard's log.

Running it

from moira.workflow import Budget, ClaudeCodeModel, Controller, OllamaModel, Workflow, load_owl

source, target = load_owl("data/MouseHuman/mouse.owl"), load_owl("data/MouseHuman/human.owl")
controller = Controller(local=OllamaModel("llama3.1"), api=ClaudeCodeModel("claude-sonnet-5-5"),
                        budget=Budget(api_calls=20))
result = Workflow(controller).integrate(source, target, place=100)
print(len(result.matches), result.validation.removed, result.tiers)

Cost

Every model call is recorded on moira.costs.METER with its tokens, seconds, and list-price dollars. experiments/agentic_workflow compares the routed policy with a local model alone, an API model alone, a call cap, and evidence alone, on all three tasks; see Experiments and the live showcase.
